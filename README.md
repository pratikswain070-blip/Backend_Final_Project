# Backend Final Project

This repository contains the complete **EnergySaver - Smart Home Energy Manager** project.

## Directory Structure

```
Backend_Final_Project/
└── EnergySaver/                   # Complete Full-Stack Smart Home Energy Management System
    ├── server.js                  # Entry point (REST API, Swagger, Socket.io & Frontend)
    ├── package.json               # Dependencies and scripts
    ├── seed.js                    # Database seed script
    ├── EnergySaver.postman_collection.json # Postman API test collection
    ├── README.md                  # Comprehensive project documentation
    ├── frontend/                  # Interactive single-server dashboard UI
    ├── controllers/               # 11 REST API controllers
    ├── routes/                    # 11 Express router modules
    ├── models/                    # 8 Mongoose schemas
    ├── middleware/                # Auth, Role, Validation & Error middlewares
    ├── sockets/                   # Real-time Socket.io handlers
    └── swagger/                   # OpenAPI 3.0 live Swagger documentation
```

For full documentation, API endpoints, and setup instructions, see [EnergySaver/README.md](EnergySaver/README.md).
